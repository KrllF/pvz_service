## ПВЗ Сервис 
## Описание проекта 

ПВЗ Сервис  — это приложение для управления пунктами выдачи заказов (ПВЗ). Оно предоставляет возможности для работы с заказами, включая их прием, выдачу, возврат, а также аудит действий и мониторинг бизнесовых показателей. Проект реализован с использованием современных технологий, таких как PostgreSQL, Kafka, gRPC, метрики и асинхронная обработка данных. 
Функциональность 
Основные возможности 

## Управление заказами : 
        Принятие заказов от курьеров.
        Выдача заказов клиентам.
        Возврат заказов курьерам или в ПВЗ.
        Получение истории заказов.
         

## Упаковка заказов : 
        Поддержка трех типов упаковки: пакет, коробка, пленка.
        Автоматическое увеличение стоимости заказа в зависимости от типа упаковки.
        Проверка допустимого веса для каждого типа упаковки.
         

## Аудит-логи : 
        Логирование изменений статуса заказов и запросов/ответов API.
        Асинхронная обработка аудит-логов с использованием воркер пула.
        Гарантированная доставка логов в Kafka через паттерн Transactional Outbox .
         

## Кэширование : 
        Кэш актуальных заказов клиентов для быстрого доступа.
        Обновление кэша в фоновом режиме(cron job).
         

## Метрики и мониторинг : 
        Сбор кастомных метрик для отслеживания бизнесовых показателей(prometheus, grafana).
        Middleware для сбора технических метрик (RPS, ok/error rate).
        Трейсинг запросов внутри приложения(opentracing, jaeger).
         

## API : 
        RESTful API.
        gRPC API.
         
Для проекта использовалась чистая архитектура
